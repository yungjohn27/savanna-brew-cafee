SAVANNA BREW CAFE WEBSITE

Project files:
- index.html: Home page
- about.html: About page
- menu.html: Menu page
- gallery.html: Gallery page
- contact.html: Contact page
- css/style.css: Shared stylesheet
- images/: Local SVG illustrations used by the gallery and home page

HOW TO UPLOAD TO GITHUB
1. Create a new PUBLIC repository on GitHub.
2. Open the repository and choose Add file > Upload files.
3. Open this project folder on your computer.
4. Select ALL the files and folders INSIDE this folder (index.html, about.html, css, images, etc.).
5. Drag them into GitHub's upload area and click Commit changes.
6. Check that index.html is visible on the repository's main Code page.
7. Open Settings > Pages.
8. Under Build and deployment, choose Deploy from a branch.
9. Select branch main and folder /(root), then Save.
10. Wait for deployment. The website address will be:
    https://YOUR-GITHUB-USERNAME.github.io/REPOSITORY-NAME/

IMPORTANT
- Keep index.html in the repository root.
- Do not upload only the ZIP file.
- This is an HTML and CSS demonstration. The reservation form does not send or store bookings.
